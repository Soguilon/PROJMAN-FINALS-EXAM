# PROJMAN Finals — PMIS Interactive Practice Exam

A single-file HTML5/CSS3/vanilla-JavaScript multiple-choice practice exam adapted from the supplied PROJMAN Finals reviewer.

## Run
Open `index.html` in a modern browser. No server, database, account, framework, or external dependency is required.

## Coverage
- Chapter 1: Communication, Collaboration, and Stakeholder Management in PMIS
- Chapter 2: Project Monitoring, Control, and Reporting Using PMIS
- 76 four-option multiple-choice questions with college-level application and scenario prompts

## Features retained from the reference app
- One question at a time with randomized answer choices
- Immediate correct/incorrect feedback and explanations
- Progress bar and question count
- Results with score, accuracy, and performance message
- Full answer review and retake
- Light/dark theme with saved preference
- Responsive mobile/tablet/desktop layout, keyboard focus, reduced-motion support

Questions are grounded in the supplied five-page PROJMAN PDF. Where the PDF provides a formula or process sequence, the quiz tests that exact formula or sequence.
